# 簡易書籍管理系統：參考答案

以 Python 讀取 JSON 書籍資料，提供瀏覽、新增、查詢、切換借閱狀態、統計及匯出功能。

在本目錄執行 `python app.py`。程式每次啟動都讀取 `books.json`；選擇選單 6 後，將目前的全部資料寫入 `output.json`。重新匯出會覆寫 `output.json`。

使用 Python 標準函式庫，不需要安裝第三方套件。

# 題目：簡易書籍管理系統

請使用 Python 設計一個命令列版的簡易書籍管理系統。

程式啟動後，從 JSON 檔案讀入書籍資料，並以「**一個 list 存放多個 dict**」的方式管理資料。使用者可以瀏覽、新增、查詢書籍，變更借閱狀態，並將目前資料匯出為 JSON 檔案。

本題不需要使用資料庫，也不需要圖形介面或第三方套件。

## 一、準備書籍資料

請在專案根目錄建立 `books.json`，將下列內容存入檔案，並以 **UTF-8 編碼**儲存。

```json
[
    {
        "id": "B001",
        "title": "Python 入門",
        "author": "王小明",
        "price": 450,
        "borrowed": false
    },
    {
        "id": "B002",
        "title": "資料分析基礎",
        "author": "陳美玲",
        "price": 680,
        "borrowed": true
    },
    {
        "id": "B003",
        "title": "Python 實作練習",
        "author": "林大華",
        "price": 520,
        "borrowed": false
    },
    {
        "id": "B004",
        "title": "程式設計的思考",
        "author": "張雅婷",
        "price": 399,
        "borrowed": false
    }
]
```

每筆書籍資料都是一個 `dict`，欄位如下：

| 欄位名稱 | 說明 | 型別 |
| --- | --- | --- |
| `id` | 書籍編號，不可重複 | `str` |
| `title` | 書名 | `str` |
| `author` | 作者 | `str` |
| `price` | 價格，須為大於 0 的整數 | `int` |
| `borrowed` | 借閱狀態：`true` 表示已借出，`false` 表示可借閱 | JSON 布林值 |

讀入 Python 後，JSON 的 `true`、`false` 會分別轉為 `True`、`False`。

### 資料如何保存？

- 程式每次啟動時，讀取 `books.json`。
- 新增書籍或變更借閱狀態時，資料只會保存在目前執行中的 `list`。
- 選擇「匯出書籍資料」後，程式才會將目前的全部資料寫入 `output.json`。
- 程式不需要修改 `books.json`，也不需要在下次啟動時讀取 `output.json`。
- 如果離開前沒有匯出，本次新增或變更的資料就不會保存。

- 選擇離開時，顯示「系統已退出」並結束程式。

## 三、功能需求

### 1. 讀取書籍資料

程式啟動時，從 `books.json` 讀入資料。

- 使用 `with` 開啟檔案，並指定 UTF-8 編碼。
- 使用 `json.load()` 將 JSON 資料讀入 Python 的 `list`。
- 本題可假設 JSON 格式正確時，內容一定符合前述欄位與資料型別。
- 如果檔案不存在，或 JSON 格式錯誤，分別顯示對應的錯誤提示，然後結束程式。
- 讀取失敗時，不得以空資料取代原始資料後繼續匯出。

**例外處理提示：**

- `FileNotFoundError`：找不到要讀取的檔案。
- `ValueError`：讀取的內容不是正確的 JSON 格式時，可以用來處理錯誤。
- 也可以使用更明確的 `json.JSONDecodeError` 處理 JSON 格式錯誤；它是 `ValueError` 的子類別。使用前須先匯入 `json` 模組。
- 讀取檔案時，也可能發生其他檔案作業錯誤，例如沒有讀取權限。可以使用 `OSError` 處理這類錯誤。
- 如果同時處理 `FileNotFoundError` 和 `OSError`，請先處理 `FileNotFoundError`，因為它是 `OSError` 的子類別。

### 2. 顯示全部書籍

依照資料在 `list` 中的順序，逐筆顯示書籍資料。

- 顯示編號、書籍編號、書名、作者、價格及借閱狀態。
- 使用 `enumerate()` 產生從 **1** 開始的顯示編號。
- 已借出的書籍顯示「已借出」，其餘顯示「可借閱」。
- 使用**條件表達式**決定每筆書籍要顯示的借閱狀態。
- 使用 **f-string** 格式化輸出。價格須有千分位符號，並靠右對齊。
- 資料為空時，顯示「目前沒有書籍資料」。

顯示編號只是畫面上的順序，不是書籍編號。例如第 1 筆資料的書籍編號可能是 `B001`。

**提示：**`enumerate(資料, 1)` 可以產生從 1 開始的編號。條件表達式的寫法是 `值1 if 條件 else 值2`。f-string 的格式設定可以同時指定靠右對齊與千分位，例如 `{數值:>10,}`。

### 3. 新增書籍

依序輸入書籍編號、書名、作者及價格。

- 輸入前後的空白須移除。
- 書籍編號、書名及作者不可為空；輸入空白時，提示並重新輸入該欄位。
- 書籍編號不可與現有資料相同。若重複，提示並重新輸入書籍編號。
- 書名與作者可以重複。
- 價格須轉換為 `int`，且必須大於 0。
- 價格輸入文字、小數、空白、零或負數時，提示並重新輸入價格，不必重新輸入前面的欄位。
- 轉換價格時，須使用 `try...except` 處理 `ValueError`。
- 新增的書籍預設為「可借閱」，也就是 `borrowed` 設為 `False`。
- 所有欄位都正確後，才將新的 `dict` 加入 `list`，並顯示「新增成功」。

**提示：**`input()` 取得的是字串。可以先用 `strip()` 移除前後空白，再使用 `int()` 轉型。`int()` 遇到無法轉成整數的內容時會引發 `ValueError`；轉型成功後，仍要檢查價格是否大於 0。

### 4. 查詢書籍

使用者輸入書名關鍵字，程式列出所有書名包含該關鍵字的書籍。

- 查詢前移除關鍵字前後的空白；空白關鍵字須提示並重新輸入。
- 英文字母查詢時不區分大小寫。例如，輸入 `python` 可以找到「Python 入門」。
- **必須使用列表推導式（List Comprehension）** 產生符合條件的書籍 `list`。
- 查詢結果使用與「顯示全部書籍」相同的欄位。
- 沒有符合的書籍時，顯示「查無符合的書籍」。
- 查詢不得改變原本的書籍資料。

**提示：**`lower()` 可以將字串轉成小寫；`in` 可以判斷書名是否包含關鍵字。列表推導式可搭配 `if` 篩選資料，語法為 `[運算式 for 變數 in 資料 if 條件]`。

### 5. 變更借閱狀態

使用者輸入完整的書籍編號，切換該書的借閱狀態。

- 編號需完全相同才算找到。輸入編號前後的空白須移除，英文字母則區分大小寫。
- 找到書籍時：
  - 原本可借閱，改成已借出。
  - 原本已借出，改成可借閱。
- 再次輸入同一個書籍編號時，狀態會再切換回來。
- 顯示書名與變更後的狀態。
- 查無編號時，顯示「查無此書籍編號」，並回到主選單。

**提示：**`not` 可以將布林值 `True` 變成 `False`，也可以將 `False` 變成 `True`。

### 6. 顯示最後 3 筆書籍與統計

依照資料在 `list` 中的順序，顯示**最後 3 筆**書籍，並顯示全部書籍的統計資料。

- 必須使用 **切片（slicing）** 方式取得最後 3 筆。
- 不足 3 筆時，顯示目前所有資料。
- 統計資料包含書籍總數、可借閱數量、已借出數量、全部書籍價格合計及平均價格。
- 平均價格顯示至小數點後兩位；合計金額須使用千分位格式。
- 沒有書籍資料時，顯示「目前沒有書籍資料」，不計算平均價格。

> 最後 3 筆是指目前 `list` 中排序最後的書籍。程式不需要記錄新增時間，也不需要依書名或價格排序。

**提示：**`資料[-3:]` 可以取出串列最後 3 筆。平均價格可用價格合計除以書籍總數；計算前請先確認總數不是 0。

### 7. 匯出書籍資料

將目前 `list` 中的**全部書籍資料**寫入 `output.json`。

- 使用 `with` 開啟檔案，並指定 UTF-8 編碼。
- 使用 `json.dump()` 寫入 JSON。
- 輸出的 JSON 須有適當縮排，且中文可直接閱讀。
- 匯出成功後，顯示匯出的筆數。
- 無法寫入時，使用例外處理顯示錯誤訊息，並回到主選單；不得顯示匯出成功。
- 若 `output.json` 已存在，再次匯出時可覆寫它。

**提示：**`json.dump()` 可搭配 `ensure_ascii=False` 保留中文字，並用 `indent` 設定縮排。若檔案無法寫入，可以使用 `OSError` 處理檔案作業錯誤。

## 四、自訂函式與專案結構

請將自訂函式放在 `pkg` 套件中的模組，再由主程式匯入並呼叫。

專案結構至少包含：

```text
專案目錄/
├─ app.py
├─ books.json
├─ README.md
├─ .gitignore
├─ LICENSE
└─ pkg/
   ├─ __init__.py
   └─ book_tools.py
```

執行匯出後，專案目錄會產生 `output.json`。

請在 `pkg/book_tools.py` 中至少定義下列函式。以下只列出函式的名稱、參數、回傳型別與功能，**請自行撰寫函式內容**：

```python
def read_books(file_name: str) -> list:
    """讀取 JSON 書籍資料並回傳。"""


def write_books(books: list, file_name: str) -> None:
    """將書籍資料寫入 JSON 檔案。"""


def search_books(books: list, keyword: str) -> list:
    """依書名關鍵字查詢書籍並回傳結果。"""


def show_books(books: list) -> None:
    """顯示書籍資料。"""
```

- 每個自訂函式都須有 **docstring**，說明函式功能。需要參數或回傳值的函式，也須說明參數或回傳值。
- 每個自訂函式的參數與回傳值都須加上**型別提示（Type Hints）**。
- 可依需要自行增加其他函式。
- `app.py` 必須匯入並實際使用 `pkg.book_tools` 中的函式。
- `README.md` 須說明程式功能、執行方式及資料匯出方式。
- 專案須包含 `LICENSE` 授權檔案；可以使用 GitHub 建立專案時提供的授權範本，例如 MIT License。

### PEP 8 程式風格

請參考 PEP 8 撰寫程式，並留意以下基本原則：

- 每層縮排使用 4 個空白，不要混用 Tab 與空白。
- 函式與變數使用有意義的名稱，並以小寫字母與底線命名，例如 `book_id`、`read_books`。
- 運算子周圍及逗號後適當加入空白，括號內側不要加上不必要的空白。
- 函式之間保留適當空行，過長的程式碼適當換行。
- 註解與 docstring 應清楚說明程式。
